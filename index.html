Problema

Decisión

Distribución de cartera de cobranza · ramo SPF

Sector asegurador · .NET + SQL Server
180Kregistros / mes

Problema

La asignación mensual de cartera tomaba días completos de trabajo manual al equipo de cobranza.

Decisión

Herramienta .NET que lee el datamart, aplica la lógica de distribución y clasifica la cartera en pendientes, anulados y cobrados, con reportes de desempeño generados automáticamente.

Resultado

El proceso pasó de días a minutos. El equipo dejó de operar la distribución y pasó a trabajar sobre sus resultados.
